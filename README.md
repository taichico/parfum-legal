# parfum-legal

iOS アプリ **Parfum** のプライバシーポリシーと利用規約を公開するためのリポジトリ。

- プライバシーポリシー … https://taichico.github.io/parfum-legal/privacy/
- 利用規約 … https://taichico.github.io/parfum-legal/terms/

## ⚠️ ここを直接編集しない

**原本はアプリ本体のリポジトリ（private）の `docs/` にある。** 文書はアプリの
実装に合わせて書かれていて、実装を変えたら文書も直す、という対応関係を
そちらのチェックリストが持っている。ここだけ直すと原本と食い違う。

更新するときは原本を直してから、2ファイルを上書きして push する。

## なぜリポジトリを分けているか

アプリ本体は private で、そちらの `docs/` には運用の内部事情（本番プロジェクトの
識別子・サービスアカウント・セキュリティルールの設計・鍵の使い方）も入っていた。
GitHub Pages は指定フォルダを丸ごと公開するので、**公開してよいものだけを持つ
リポジトリを分けた**。設定で除外する形にすると、一行消えただけで漏れる。
